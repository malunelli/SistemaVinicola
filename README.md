# Sistema de Gerenciamento de Vinícola

Projeto acadêmico desenvolvido em Java para a disciplina de Programação Orientada a Objetos (POO) da UTFPR.

## Sobre o projeto

O Sistema de Gerenciamento de Vinícola é uma aplicação desktop desenvolvida para organizar cadastros e operações de venda de uma vinícola. O sistema permite gerenciar clientes, vendedores e bebidas, registrar vendas e gerar relatórios das operações realizadas.

## Funcionalidades

- **Cadastro de clientes:** registro e gerenciamento das informações dos clientes.
- **Cadastro de bebidas:** gerenciamento de bebidas dos tipos vinho, espumante e suco.
- **Cadastro de vendedores:** registro e gerenciamento dos vendedores.
- **Registro de vendas:** seleção do cliente, da bebida e da quantidade, além da definição da forma de pagamento.
- **Descontos:** consideração de descontos aplicáveis ao cliente.
- **Comissões:** cálculo da comissão do vendedor relacionada à venda.
- **Relatórios:** geração de relatórios referentes aos cadastros e às operações realizadas no sistema.

## Organização do projeto

O projeto é organizado em componentes que separam as responsabilidades da aplicação, incluindo:

- Classes Java que implementam as funcionalidades e regras de negócio.
- Formulários de interface gráfica (`.form`) desenvolvidos no NetBeans.
- Componentes relacionados ao armazenamento e à consulta de dados.
- Tratamento de exceções.

## Tecnologias e ferramentas

- Java
- Programação Orientada a Objetos (POO)
- Apache NetBeans
- Maven

## Objetivo acadêmico

Aplicar conceitos de orientação a objetos no desenvolvimento de uma aplicação desktop, trabalhando com cadastros, regras de negócio, operações de venda, relatórios, interfaces gráficas e tratamento de exceções.
